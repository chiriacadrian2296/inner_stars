# Current production UI captures

Generated from the current Flutter widgets with `tool/capture_landing_test.dart`.
Run `flutter test tool/capture_landing_test.dart` from the repository root to
refresh both languages. All preferences are mocked; no real user data is read.

The fixture contains eight areas, two projects, two victories, one goal and one
habit. Screens are the production Sky browser, constellation map, activity
reader and project form. Fonts and Material icons are loaded explicitly.

The legacy `shots/` assets are retained only for the preserved classic landing.
